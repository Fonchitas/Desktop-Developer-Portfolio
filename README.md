# Analogue Photography Portfolio Template

Live: (pon aquí tu link de GitHub Pages)

## Description
Reusable portfolio template for analogue photography with a cinematic dark theme and warm “light leak” accents.
Includes mouse-driven XY canvas navigation (pan in all directions), semantic HTML, layered CSS architecture, and a custom 404.

## Tech Stack
HTML5, CSS3, Vanilla JavaScript (ES6)

## Local Setup
Open `index.html` with a local server (VS Code Live Server recommended).

## Customization
- Edit panel content inside `index.html` (`panel-home`, `panel-work`, `panel-about`, `panel-contact`)
- Adjust stage size and panel positions in `assets/css/layout.css`
- Tweak motion (inertia, drift) in `assets/js/main.js`
