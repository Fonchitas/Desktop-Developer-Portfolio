Project Overview
An immersive, innovative photography portfolio featuring an infinite panning world where visitors can explore 23+ photographs in a unique browsing experience. This project demonstrates advanced web design techniques including GSAP animations, glassmorphism UI, and seamless transitions between exploration and traditional navigation modes.
Key Features
✨ Infinite Panning World - Mouse/touch drag navigation through a virtual photography gallery
🎨 Glassmorphism UI - Modern frosted-glass effect throughout
🌗 Light/Dark Mode - Full theme switching with smooth transitions
📱 Fully Responsive - Mobile-first design optimized for all devices
🎬 GSAP Animations - Professional entrance sequences and smooth transitions
🖼️ Immersive Detail View - Click any photo to see full project galleries

Tech Stack

HTML5 - Semantic structure
CSS3 - Custom properties, glassmorphism, fluid typography
Bootstrap 5.3 - Responsive grid system (via CDN)
GSAP 3.12 - Advanced animations and ScrollTrigger (via CDN)
JavaScript (ES6+) - Vanilla JS for infinite world logic and state management

Why This Stack?
This project uses Second Grade requirements from the Web Atelier course:

Bootstrap for rapid responsive layout in content sections
GSAP for complex timeline animations and scroll effects
Vanilla JavaScript for custom infinite panning logic
All dependencies via CDN (no build tools required)


Local Development Setup
Prerequisites

Modern web browser (Chrome, Firefox, Safari, Edge)
Local web server (optional but recommended)

Installation

Clone the repository

bash   git clonehttps://github.com/Fonchitas/Desktop-Developer-Portfolio.git
   cd portfolio-analogue-template

Open in browser
Option A - Direct file access:

bash   open index.html
Option B - Local server (recommended):
bash   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if installed)
   npx serve
   
   # Using PHP
   php -S localhost:8000
Then navigate to http://localhost:8000

Start developing!

Edit files in assets/css/ and assets/js/
Refresh browser to see changes
Check browser console for any errors
